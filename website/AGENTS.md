# Website instructions

Develop and preview this website locally. Do not publish, deploy, or add hosted infrastructure unless the user explicitly requests it. Repository storage and pull requests do not authorize deployment.

Keep the site simple and unstylized, with no product listings until requested. Add product details, contact addresses, and social links only when provided; do not invent them.

The HTML files in `dist/` are the canonical pages, and `dist/styles.css` owns shared styles. No framework or build step is needed. Keep all five navigation links consistent across pages and mark the current page with `aria-current="page"`.
